# iPhone Chat Video Builder Pro v4

ეს ვერსია უფრო გლუვ render-ზეა გადაწყობილი.

რა შევცვალე:
- default ვიდეო გახდა **20 FPS**
- default quality გახდა **Smooth HD**
- render-ის დროს მძიმე ეფექტები ითიშება, რომ ვიდეო ნაკლებად ჭედავდეს
- status-ში უკეთ ჩანს რა პარამეტრებით მიდის render

საუკეთესო პარამეტრები:
- **Smooth HD + 20 FPS** → ყველაზე კარგი ბალანსი
- **Sharp + 20 FPS** → უფრო ლამაზი, მაგრამ უფრო მძიმე
- **Ultra + 24/30 FPS** → მხოლოდ ძლიერ კომპიუტერზე

მნიშვნელოვანი:
ბრაუზერში პირდაპირ ვიდეოს გენერაცია მაინც უფრო მძიმეა, ვიდრე screen recording.
თუ აბსოლუტურად ყველაზე გლუვი შედეგი გინდა, Run + screen recorder ისევ საუკეთესო ვარიანტია.
