# iPhone Chat Video Builder

მზადაა GitHub Pages-ზე ასატვირთად.

## ფაილები
- `index.html`
- `style.css`
- `script.js`

## როგორ გაუშვა
1. ატვირთე ეს ფაილები ერთ რეპოში GitHub-ზე
2. გახსენი **Settings → Pages**
3. Source აირჩიე: **Deploy from a branch**
4. Branch: **main** / root
5. Save
6. რამდენიმე წამში მოგცემს ლინკს

## როგორ გამოიყენო
1. მარცხნივ შეავსე სახელები, დრო, ბატარეა, ავატარები
2. Add Message-ით დაამატე მესიჯები
3. თითოეულ მესიჯზე აირჩიე:
   - ვინ წერს
   - ტექსტი
   - delay
   - typing დრო
   - ხმა
4. დააჭირე **Run**
5. Countdown-ის დროს ჩართე screen recorder
6. თუ გინდა ვიდეოსთვის სუფთა ეკრანი, ჩართე **Record Mode**

## დამატებითი რჩევა
- fullscreen stage გამოიყენე უფრო სუფთა ჩანაწერისთვის
- speed 1x ან 1.25x საუკეთესოა
- მოკლე და გრძელი მესიჯების შერევა უფრო რეალურ ეფექტს იძლევა
- emoji და read labels რეალურობას მატებს

## შენიშვნა
ხმები გენერირდება ბრაუზერში და ზოგ ბრაუზერში პირველად შეიძლება Run-ზე ერთხელ დაკლიკება დასჭირდეს აუდიოსთვის.
