# iPhone Chat Video Builder Pro

ეს ვერსია უკვე აკეთებს:

- ჩატის ანიმაციას
- სცენების შენახვას ბრაუზერში
- JSON ფაილად შენახვა/ჩატვირთვა
- პირდაპირ WEBM ვიდეოს გენერაციას და ჩამოტვირთვას

## მთავარი შენიშვნა
პირდაპირ MP4-ის გენერაცია ბრაუზერში არასტაბილურია, ამიტომ ყველაზე საიმედოდ გაკეთებულია **WEBM** export.

## როგორ გამოიყენო
1. GitHub-ზე ატვირთე `index.html`, `style.css`, `script.js`
2. ჩართე GitHub Pages
3. გახსენი საიტი
4. ააწყე სცენა
5. თუ გინდა უბრალოდ ნახვა — `Run`
6. თუ გინდა ვიდეო ფაილი — `Render Video WEBM`

## სცენების შენახვა
- სცენის სახელი ჩაწერე
- დააჭირე `Save Scene`
- რამდენიც გინდა იმდენი სცენა შეგიძლია შეინახო
- `Load Selected`-ით ჩატვირთავ

## ვიდეოს ხარისხი
- FPS: 10-12 კარგი ბალანსია
- Quality Better ან High უკეთეს სურათს იძლევა, მაგრამ უფრო ნელია
